# Proposal: button-rating

## What

基于 GPIO9 单个按钮，为当前展示的 RSS 条目添加评价功能。

双击按钮进入评价模式，屏幕右侧出现两个几何图标（喜欢 / 不喜欢）。在评价模式下，每次单击在三个状态间循环切换（无选择 → 喜欢 → 不喜欢 → 无选择）。5 秒无操作后自动提交当前选择并退出评价模式。

## Why

用户长时间被动浏览 RSS 内容，缺乏反馈渠道。评价数据未来可用于个性化推荐、内容过滤或统计分析。GPIO9 是板载唯一可用按钮，需在不增加硬件的前提下复用该按钮实现多种交互语义。

## Non-goals

- 不实现长按手势
- 不实现评价数据的远端 HTTP 上报（当前只打印日志，接口预留占位函数）
- 不修改 WiFi 配网流程中的按钮行为
- 不引入新的 FreeRTOS 任务

## Constraints

- GPIO9 为低电平有效（内部上拉），按下时拉低
- ESP32-C3 单核，ISR 必须极简，所有手势判断逻辑在任务上下文完成
- 图片区域（y: 0~219）直接写 TFT，绕过 LVGL；评价图标同样直接写 TFT，避免 LVGL 脏区覆盖图片
- 进入评价模式后倒计时暂停；退出评价模式后从剩余时间继续倒计时
- 双击检测防抖 50ms，双击时间窗口 400ms，评价超时 5000ms
